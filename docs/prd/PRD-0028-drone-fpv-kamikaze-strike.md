# PRD-0028 Drone FPV Kamikaze Strike

## Summary

在 `v42` 已建立的玩家无人机基础上，追加一条正式的 `FPV 自杀式冲击` 玩法链：玩家先用 `KEY_KP_5` 放飞无人机，在无人机处于 `active` 状态时，按下鼠标右键切换到无人机 `FPV/ADS` 视角；此时画面进入黑白红外风格滤镜，准星可见，鼠标接管自由视角。玩家在该模式下按下鼠标左键后，即锁定当前准星下的目标点，随后无人机不再接受人工操控，而是以高速第一视角直接扑向目标并自爆。爆炸结束后，系统自动切回玩家视角并结束本轮无人机出击。

## Problem

`v42` 的无人机目前只具备第三人称摄影式飞行基础，还没有形成强烈的攻击闭环。用户现在需要的不是“无人机上挂一把枪”，而是一条更极端、更具战场感的攻击表达：`右键进入 FPV 搜索 / 左键锁定 / 第一视角决绝冲刺 / 爆炸后切回玩家`。这条链路必须保持沉浸感，不能退化成普通投射物，也不能退化成简单的“切镜头 + 瞬间爆炸”。

## Goals

- 在无人机 `active` 状态下，提供正式的 `FPV/ADS` 视角切换。
- 在 `FPV/ADS` 状态下，提供可见准星、鼠标自由视角和黑白红外滤镜。
- 在 `FPV/ADS` 状态下，允许鼠标左键锁定当前准星目标并触发不可取消的自杀式冲击。
- 在冲击全过程中，保持无人机第一视角与红外滤镜，不允许偷省略中间冲刺镜头。
- 在爆炸 closeout 后，自动恢复玩家视角与控制权，并把无人机系统收口回 `stowed`。

## Non-Goals

- 不做常规机炮、导弹或其它可持续射击武器。
- 不做热成像目标描边、敌我识别 UI、锁定框或复杂 HUD。
- 不做无人机残骸持久化、二次爆炸链、EMP、穿甲等扩展伤害类型。
- 不做联机同步、录像回放、任务脚本接入或关卡专用旁路。
- 不做可取消的自杀冲击；一旦锁定并提交，默认不可回退。

## User Experience

1. 玩家按 `KEY_KP_5` 放飞无人机，进入常规第三人称飞行。
2. 玩家按下鼠标右键，无人机切到 `FPV/ADS`：
   - 画面变为黑白红外滤镜。
   - 准星出现。
   - 鼠标可自由控制第一视角上下左右观察。
3. 玩家用准星指向任意地面、建筑、车辆或角色，按下鼠标左键：
   - 当前准星目标点被锁定。
   - 无人机进入自杀式冲击，不再接受人工移动输入。
   - 相机保持第一视角，不切回第三人称。
   - 红外滤镜持续生效直到爆炸结束。
4. 无人机撞击目标或抵达锁定点附近后爆炸。
5. 爆炸 closeout 完成后，系统切回玩家视角，恢复玩家输入，无人机回到 `stowed`。

## Functional Requirements

### FR-1 FPV/ADS Entry

- 仅当无人机 runtime 处于 `active` 时，鼠标右键才允许切换 `FPV/ADS`。
- `FPV/ADS` 必须是无人机自己的第一视角，不允许复用玩家相机冒充。
- `FPV/ADS` 默认使用比第三人称 chase camera 更窄的 `FOV`，体现 ADS 式的聚焦感。

### FR-2 FPV Visual Contract

- `FPV/ADS` 启用后，必须显示准星。
- `FPV/ADS` 启用后，必须启用黑白红外风格全屏滤镜。
- 该滤镜在 `锁定 -> 冲刺 -> 爆炸 closeout` 全程持续存在，直到系统切回玩家视角。

### FR-3 FPV Look Contract

- `FPV/ADS` 中，鼠标水平与垂直位移必须驱动无人机第一视角自由观察。
- 视角需要有合理的俯仰限制，防止完全翻折。
- 自由视角不应破坏无人机主体朝向与后续冲刺方向之间的合同；锁定时取“当前 FPV 准星方向”的目标点。

### FR-4 Target Lock Contract

- 仅在 `FPV/ADS` 中，鼠标左键触发目标锁定。
- 锁定优先取当前准星射线的真实命中点。
- 如果射线未命中可碰撞目标，则回退为沿准星前向的一段远距世界点，避免“左键无响应”。
- 锁定对象可以是地面、建筑、车辆、行人或其它可命中的世界表面；系统不要求目标必须带特定 tag。

### FR-5 Suicide Strike Contract

- 一旦锁定成功，无人机进入不可取消的自杀式冲击。
- 冲击过程不允许再接受常规 `W/A/S/D/Q/E/Space` 飞行输入，也不允许 `KEY_KP_5` 中途回收。
- 冲击必须保留完整第一视角冲刺镜头，直到撞击或接近锁定点后爆炸。
- 冲击速度必须明显高于 `v42` 常规飞行速度，观感上更接近 FPV 自杀机扑击，而不是普通巡航。

### FR-6 Explosion / Closeout Contract

- 爆炸必须对正式战斗链产生影响：
  - `city_enemy`
  - 行人爆炸解析
  - 车辆爆炸解析
  - 建筑爆炸解析
- 爆炸 closeout 后，玩家相机与输入权必须恢复。
- 无人机 runtime 必须回到 `stowed`，不残留半激活状态。

## Acceptance

1. 自动化测试必须证明：鼠标右键只在无人机 `active` 状态下切换 `FPV/ADS`。
2. 自动化测试必须证明：`FPV/ADS` 中准星可见，第三人称 drone flight 中默认不强制显示该准星合同。
3. 自动化测试必须证明：`FPV/ADS` 中红外黑白滤镜启用，锁定与冲击过程中持续启用，直到爆炸 closeout 结束。
4. 自动化测试必须证明：`FPV/ADS` 中鼠标可自由控制第一视角上下左右观察，且俯仰受限。
5. 自动化测试必须证明：`FPV/ADS` 中左键会锁定当前准星目标点；若无命中，也会生成合理的前向回退目标点。
6. 自动化测试必须证明：锁定后无人机进入不可取消的冲击状态，常规手动飞行输入失效。
7. 自动化测试必须证明：冲击全程维持第一视角与红外滤镜，不允许省略过程直接瞬爆。
8. 自动化测试必须证明：撞击爆炸后，玩家视角恢复、玩家输入恢复、无人机回到 `stowed`。
9. 自动化测试必须证明：爆炸会触发现有敌人/行人/车辆/建筑解析主链，而不是一套 lab-only 私有旁路。
